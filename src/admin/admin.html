Looking in more than one direction (e.g. AWS Cloud Architect and Java Architect)? Add up to 3 tracks. Resumes

Upload your resume. The file is attached to applications; its text is used for matching and AI tailoring. Put each achievement on its own line starting with “-” or “•” so it can be tailored line by line. Text is read automatically from .pdf, .docx, .txt and .md files; check it in the box below. Scanned (image-only) PDFs have no text: paste it instead. Applications always get a PDF: your uploaded PDF, or a clean PDF made from the text (kept in sync when you edit it).

AI settings

Matching works offline without AI. AI adds deeper JD analysis, honest resume tailoring and drafted answers. Pick a free option:

  • Chrome built-in AI — no key, no account; runs on this computer, so nothing leaves it. Needs a recent desktop Chrome and a one-time model download. Smaller than the cloud models: fine for answers and skills, slower and simpler for resume tailoring.
  • Google Gemini — free API key: aistudio.google.com/apikey (sign in with a personal Google account → Create API key). Generous free limits, but Google doesn't offer the free tier to every account or region: if AI Studio asks you to "set up billing", use Groq instead.
  • Groq — free API key: console.groq.com/keys. Free with no billing or card. Very fast; its free tier has a per-minute limit, so tailoring may pause for a few seconds and retry automatically.
  • OpenRouter — free key at openrouter.ai/keys; use models ending in :free. Some free models may log prompts.
  • NVIDIA NIM — free API key: build.nvidia.com (free NVIDIA Developer account → Get API Key). Generous free limits and strong open models: a good backup for tailoring.
  • Mistral — free plan API key: console.mistral.ai. A monthly free allowance. Privacy: on the free plan Mistral may train on your prompts; turn that off in its privacy settings, because your resume is personal.
  • Ollama — runs models on this computer; fully private. Start it with OLLAMA_ORIGINS="*" ollama serve.

Anthropic Claude (paid, optional) — for people who prefer Claude. Not free: an API key from console.anthropic.com is billed per use from credit you add there; a Claude.ai or Claude Code subscription does not cover it. Default model claude-opus-5-5 (best rewrites, roughly $0.20 per tailored resume). To spend less, type claude-sonnet-5-5 (roughly $0.10) or claude-haiku-5-5 (under a cent) as the model.

Why not log into free ChatGPT / Claude / Gemini chat websites? Automating those consumer chat apps breaks their terms and stops working whenever their UI changes. Free API keys are the supported, reliable way.
